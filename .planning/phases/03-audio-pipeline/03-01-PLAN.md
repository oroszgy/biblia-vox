## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network→local filesystem | Untrusted remote M3U/MP3 data is parsed and written locally |
| CLI args→path writes | User-provided identifiers influence destination paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | T | discovery parser | mitigate | Normalize/validate playlist paths and reject absolute/parent traversal before path joins |
| T-03-02 | D | parallel downloader | mitigate | Enforce worker/timeouts/retry caps and skip-existing idempotency to bound resource usage |
| T-03-03 | R | batch download reporting | mitigate | Emit deterministic per-item status summary (downloaded/skipped/failed) for reproducibility |
| T-03-04 | I | downloaded media | accept | Source files are public religious audio, no sensitive payloads expected |
</threat_model>
