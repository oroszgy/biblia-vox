<objective>
Implement the cross-source completeness and coverage validation engine comparing the fixed SZIT JSONL (`szit-fixed.jsonl`) and parsed MEK JSONL (`mek.jsonl`) corpora.

Purpose: Detect and flag discrepancies (missing books, chapters, verses, and textual differences) between the two translations to verify corpus coverage and accuracy before entering alignment stages.

Output:
- New validation module `bibliavox/text/cross_validator.py` with comprehensive unit tests in `tests/test_cross_validator.py`
- Typer CLI command `bibliavox text cross-validate` generating a Rich table summary
- Discrepancy report saved as a flat JSONL diff at `data/processed/text/text-discrepancies.jsonl`
- Taskfile target `text:cross-validate`
</objective>
