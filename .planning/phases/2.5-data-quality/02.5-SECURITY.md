# Phase 2.5 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| CLI input -> local filesystem | User-provided CLI flags choose input/output file paths for conversion/fix steps | Local file paths, generated JSONL content |
| Raw source file -> parser pipeline | `H_Kaldi_SZIT.json` and JSONL lines are parsed into in-memory records | Untrusted/malformed text payloads |
| Processing modules -> artifact outputs | Converter/splitter write normalized/split artifacts to `data/processed/text/` | Structured verse records written to disk |
