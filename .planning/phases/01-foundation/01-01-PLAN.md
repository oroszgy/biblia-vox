Define a `Book` dataclass with fields: `usx_code` (str, e.g., "GEN"), `hungarian_name` (str, e.g., "Teremtés"), `abbreviation` (str, e.g., "Ter"), `book_number` (int, e.g., 101 for Teremtés), `testament` (str, "OT" or "NT"), `deuterocanonical` (bool).

Implement these functions:
- `load_books(data_dir: Path | None = None) -> list[Book]` — loads from `data/reference/books.json`. If `data_dir` is None, resolve relative to repo root (3 levels up from `bibliavox/reference/books.py`).
- `lookup_by_abbreviation(abbrev: str, books: list[Book] | None = None) -> Book | None` — case-insensitive lookup by Hungarian abbreviation. Returns None if not found.
- `lookup_by_usx_code(usx_code: str, books: list[Book] | None = None) -> Book | None` — lookup by USX code.
- `get_all_books(books: list[Book] | None = None) -> list[Book]` — returns all 73 books in canonical order.

The module should have a module-level `_BOOKS` cache that loads once on first access.

**schema.py implementation (per D-02):**

Define a `BookSchema` dataclass with fields: `usx_code` (str), `chapter_count` (int), `chapters` (dict[int, int] mapping chapter number to verse count).

Implement these functions:
- `load_versification(data_dir: Path | None = None) -> list[BookSchema]` — loads from `data/reference/versification.json`.
- `get_chapter_count(usx_code: str, schemas: list[BookSchema] | None = None) -> int` — returns number of chapters for a book.
- `get_verse_count(usx_code: str, chapter: int, schemas: list[BookSchema] | None = None) -> int` — returns number of verses in a specific chapter.
- `get_versification(usx_code: str, schemas: list[BookSchema] | None = None) -> BookSchema | None` — returns full schema for a book.

**generate_reference.py implementation (per D-03):**

Create `scripts/generate_reference.py` that:
1. Fetches the `tdverse` data from szentiras.eu GitHub repo (raw file URL: `https://raw.githubusercontent.com/szentiras/szentiras.hu/main/data/tdverse.csv` or similar — check the actual repo structure)
2. Parses the CSV/data to extract book info (USX codes, Hungarian names, abbreviations, book numbers)
3. Builds chapter/verse counts from the `gepi` encoding: `{bookNum}{chapter:3d}{verse:3d}00`
4. Writes `data/reference/books.json` (73 books) and `data/reference/versification.json` (chapter/verse counts)
5. Includes a `--source` flag for local file path fallback
6. Prints summary: "Generated books.json ({N} books) and versification.json ({M} books)"

**config.py implementation (per D-09, D-10):**

Create `bibliavox/config.py` using Pydantic Settings:

```python
from pathlib import Path
from pydantic_settings import BaseSettings, SettingsConfigDict

class BibliavoxSettings(BaseSettings):
    model_config = SettingsConfigDict(
        env_prefix="BIBLIAVOX_",
        env_file=".env",
        env_file_encoding="utf-8",
    )

    # Paths (per D-10)
    data_dir: Path = Path("data")
    cache_dir: Path = Path("data/.cache")
    reference_data_path: Path = Path("data/reference")

    # API keys (per D-10: empty default)
    szentiras_api_key: str = ""

    # Model/audio/concurrency settings deferred to later phases
```

Add a module-level convenience function:
```python
_settings: BibliavoxSettings | None = None

def get_settings() -> BibliavoxSettings:
    global _settings
    if _settings is None:
        _settings = BibliavoxSettings()
    return _settings

def reset_settings() -> None:
    global _settings
    _settings = None
```
