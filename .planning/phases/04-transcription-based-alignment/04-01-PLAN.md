  <name>task 1: create GPU Docker infrastructure</name>
  <files>docker/Dockerfile.align, docker-compose.yml</files>
  <read_first>
    - docker/Dockerfile.align
    - docker-compose.yml
  </read_first>
  <action>
    Create `docker/Dockerfile.align` using a PyTorch CUDA base image (e.g., `pytorch/pytorch:2.3.0-cuda12.1-cudnn8-runtime`). Install `faster-whisper`, `rapidfuzz`, and dependencies for VibeVoice.
    Create `docker-compose.yml` defining an `align` service. It MUST map `./data:/app/data`, pass through GPU using `deploy.resources.reservations.devices` (driver nvidia, count all, capabilities gpu), and set the working directory to `/app`.
  </action>
  <acceptance_criteria>

    - `docker-compose.yml` contains `volumes:` with `./data:/app/data`
    - `docker/Dockerfile.align` installs `faster-whisper`
  </acceptance_criteria>
  <done>Docker infrastructure is defined and validates via docker compose config.</done>
</task>
