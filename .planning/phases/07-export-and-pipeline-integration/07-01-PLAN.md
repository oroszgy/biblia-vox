Create `bibliavox/export/writer.py` with these functions:

1. `load_canonical_text(data_dir: Path) -> dict[tuple[str, int, str], str]`:
   - Reads `data_dir / "processed" / "text" / "mek.jsonl"` line by line
   - Returns dict mapping `(book, chapter_int, verse_str)` → `text`
   - Uses `json.loads(line)` per line, skips empty lines
   - Caches at module level as `_CANONICAL_TEXT` with lazy loading (pattern from books.py)

2. `normalize_confidence(scores: list[float]) -> list[float]`:
   - Takes list of raw confidence scores
   - Returns list normalized to 0-1 using divide-by-max (D-15)
   - Guard: if max(scores) == 0, returns [0.0] * len(scores)
   - Guard: if scores empty, returns []

3. `export_chapter_jsonl(matched_path: Path, audio_file: str, translation: str, output_file: Path) -> int`:
   - Reads matched JSON from `matched_path` (structure: `{chapter, model, metrics, verses}`)
   - Extracts `model` from top-level, `chapter` (e.g., "TIT 1"), splits to book + ch_num
   - Loads canonical text via `load_canonical_text()`
   - Normalizes confidence scores via `normalize_confidence()` (D-15, D-16)
   - For each verse in `data["verses"]`:
     - verse_ref = f"{book} {ch_num}:{v['verse_id']}" (D-02)
     - audio_file passed as parameter (D-03)
     - start_sec = v.get("start_sec") — None for failed (D-06)
     - end_sec = v.get("end_sec") — None for failed (D-06)
     - source = data["model"] (D-07)
     - translation = passed parameter (D-07)
     - confidence = normalized value, 0.0 for failed (D-06)
     - canonical_text = lookup from mek.jsonl, "" if not found (D-04)
     - matched_text = v.get("matched_text", "") (D-04)
     - wer = compute_wer(canonical_text, matched_text) if canonical_text else 0.0 (D-05)
     - cer = compute_cer(canonical_text, matched_text) if canonical_text else 0.0 (D-05)
   - Writes each row as `json.dumps(row, ensure_ascii=False) + "\n"` to output_file (append mode)
   - Returns number of lines written

4. `is_chapter_complete(export_path: Path, model: str) -> bool`:
   - D-13: Complete = file exists AND all verses for the given model have non-null start_sec and end_sec
   - Returns False if file doesn't exist
   - Reads line by line, checks each row where row["source"] == model
   - If any row has None start_sec or end_sec, returns False
   - If all pass, returns True

Import `compute_wer` and `compute_cer` from `bibliavox.align.evaluate`.
