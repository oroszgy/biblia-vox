Create `bibliavox/text/source.py`:
- Define `_REPO_ROOT` using same 3-level-up pattern as books.py
- Define `_DEFAULT_RAW_DIR = _REPO_ROOT / "data" / "raw" / "text"`
- Module-level cache `_SZIT_DATA: dict | None = None`
- Function `load_szit_json(data_dir: Path | None = None) -> dict`:
  - Load `H_Kaldi_SZIT.json` from data_dir (default: data/raw/text/)
  - Return parsed JSON dict
  - Cache in module global
- Function `get_chapter_verses(book_name: str, chapter: int, data: dict | None = None) -> dict[int, str]`:
  - book_name is English name (e.g., "Genesis")
  - chapter is 1-based integer
  - Return {verse_num: verse_text} with int keys
  - Raise KeyError if book/chapter not found
- Function `get_verse_text(book_name: str, chapter: int, verse: int, data: dict | None = None) -> str`:
  - Return specific verse text
  - Raise KeyError if not found

Create `bibliavox/text/mapping.py`:
- Define the Hungarian→English mapping from magyar_angol_konyvek_roviditesei.json (hardcoded dict)
- Define deuterocanonical English→USX mapping:
  ```python
  _DEUTEROCANONICAL_MAP = {
      "Tobit": "TOB",
      "Judith": "JDT",
      "Wisdom": "WIS",
      "Sirach": "SIR",
      "Baruch": "BAR",
      "1Maccabees": "1MA",
      "2Maccabees": "2MA",
  }
  ```
- Function `load_book_mapping(books: list[Book] | None = None) -> dict[str, str]`:
  - Build English→USX mapping
  - For 66 Protestant books: invert Hungarian→English to English→Hungarian, then use books.py to get USX
  - For 7 deuterocanonical: use _DEUTEROCANONICAL_MAP
  - Return {english_name: usx_code} for all 73 books
- Function `english_to_usx(english_name: str, mapping: dict[str, str] | None = None) -> str`:
  - Look up USX code by English name
  - Raise KeyError if not found
  - Use cache if mapping is None

- `tests/test_text_source.py`: Test load_szit_json, get_chapter_verses, get_verse_text
- `tests/test_text_mapping.py`: Test english_to_usx for standard and deuterocanonical books
